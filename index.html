הסיפור

איך הגעתי לפה

חיפשתי המון זמן פתרון לבעיית ה-RTL בקלוד דסקטופ. כל פעם שכתבתי בעברית הייתי רואה את הטקסט נשבר, סימני פיסוק עפים למקום הלא נכון, וערבוב עם אנגלית הופך לכאוס מוחלט.

ניסיתי בעצמי כמה פעמים לפתור את זה. בכל ניסיון קלוד פשוט קרס לי בהפעלה והייתי צריך להתקין מחדש. שאלתי המון אנשים בתחום, פתחתי שיחות, חיפשתי בכל מקום אפשרי.

רגע לפני שהתייאשתי וחשבתי שזה פשוט לא אפשרי, מצאתי שני אנשים מדהימים שבנו את הפתרון. אחד ל-Windows, אחד ל-Mac. וזה עובד.

כנראה בקלוד אין דבר כזה "אי אפשר".

התקנה ב-3 שלבים

דרך Claude Code

בלי טרמינלים. בלי פקודות מסובכות. רק העתק והדבק.

איזה מחשב יש לכם?

1

פתחו Claude Code

בכל תיקייה שתרצו. אם אין לכם, תורידו מ-claude.ai/code

2

העתיקו את הפרומפט והדביקו לקלוד

התקן לי את פאטצ' ה-RTL לקלוד דסקטופ במק.

הריפו הרשמי: https://github.com/soguy/claude-desktop-rtl-mac

עשה את הצעדים הבאים:
1. בצע git clone של הריפו לתיקייה זמנית
2. הרץ את patch.sh ובחר באפשרות 1 (Install)
3. וודא שהסקריפט סיים בהצלחה את כל השלבים, במיוחד כיבוי ה-fuse של Electron (EnableEmbeddedAsarIntegrityValidation=off) ו-codesign מחדש

חשוב מאוד: השתמש בסקריפט הרשמי patch.sh של הריפו. אל תנסה לבנות פאטצ' ידנית. בלי שלב כיבוי ה-fuse האפליקציה תקרוס בהפעלה הראשונה.

כשתסיים, אמור לי במפורש שאני צריך לפתוח את Claude-RTL מהתיקייה ~/Applications, לא את הקלוד הרגיל.
3

פתחו את Claude-RTL מהאפליקציות

כשקלוד יסיים, תהיה לכם אפליקציה חדשה בשם Claude-RTL. פתחו אותה ספציפית. לא את הקלוד הרגיל.

איך מוצאים אותה?

פתחו Finder → בתפריט העליון Go → Home → Applications → Claude-RTL.app

הפאטצ' לא נוגע בקלוד המקורי. זו אפליקציה נפרדת לחלוטין. שניהן מחוברות לאותו חשבון ולאותה היסטוריה.

1

פתחו Claude Code

אם אין לכם, תורידו מ-claude.ai/code

2

העתיקו את הפרומפט והדביקו לקלוד

התקן לי את פאטצ' ה-RTL לקלוד דסקטופ בווינדוס.

הריפו הרשמי: https://github.com/shraga100/claude-desktop-rtl-patch

עשה את הצעדים הבאים:
1. פתח PowerShell והרץ את הפקודה:
   irm https://raw.githubusercontent.com/shraga100/claude-desktop-rtl-patch/main/install.ps1 | iex
2. הסקריפט יבקש הרשאות מנהל (UAC). אישור אוטומטי.
3. בתפריט שיופיע, בחר באפשרות 1 (Install).

חשוב מאוד: השתמש בסקריפט הרשמי install.ps1 של הריפו. אל תנסה לבנות פאטצ' ידנית. הסקריפט מבצע שלבים קריטיים של הזרקת הקוד, החלפת hash בתוך claude.exe והחלפת תעודות חתימה.

כשתסיים, אמור לי שאני יכול לפתוח את קלוד דסקטופ הרגיל ולהתחיל להשתמש. אותה אפליקציה כמו תמיד, רק עם תמיכת RTL.
3

פתחו את Claude כרגיל

בוינדוס הפאטצ' משנה את האפליקציה הקיימת. אין אפליקציה חדשה. פשוט פתחו את קלוד דסקטופ כרגיל. הוא יתנהג בדיוק אותו דבר, רק עם תמיכת RTL.

הסקריפט יוצר גיבוי מלא של הקבצים המקוריים. אם משהו ישתבש, אפשר לשחזר בלחיצה אחת.

במק נוצרת אפליקציה חדשה

האפליקציה החדשה תיקרא Claude-RTL ותשב ב-~/Applications. הקלוד הרגיל שלכם נשאר תקין לחלוטין. שתי האפליקציות מחוברות לאותו חשבון.

🪟

בוינדוס הקלוד הקיים מתעדכן

אין אפליקציה חדשה. הסקריפט מעדכן את הקלוד הקיים שלכם. הוא יוצר גיבוי אוטומטי של הקבצים המקוריים, אז אפשר לשחזר בכל רגע.

שאלות נפוצות

האם זה בטוח? ▼

הקוד פתוח לחלוטין בשני הריפוז. אפשר לראות בדיוק מה הסקריפט עושה. זה מקובל בקהילת המפתחים, אבל חשוב לדעת שזה מודיפיקציה לא מורשית של אנתרופיק.

🍎 במק. אם משהו ישתבש, איך מסירים? ▼

פשוט מוחקים את Claude-RTL.app מהתיקייה ~/Applications. הקלוד הרגיל שלכם נשאר תקין לחלוטין כי הפאטצ' מעולם לא נגע בו.

🍎 במק. למה צריך אפליקציה חדשה ולא לעדכן את הקיימת? ▼

זו החלטה של מפתח הפאטצ' לטובת הביטחון שלכם. הקלוד המקורי נשאר נקי, ואם משהו ישתבש בעדכון, פשוט פותחים אותו במקום. שתי האפליקציות מחוברות לאותו חשבון, אז ההיסטוריה זמינה בשתיהן.

🪟 בוינדוס. אם משהו ישתבש, איך מסירים? ▼

מריצים שוב את אותה פקודת ההתקנה ב-PowerShell, ובתפריט בוחרים אפשרות 2 (Restore). הסקריפט שומר גיבוי מלא של הקבצים המקוריים ומשחזר אותם.

🪟 בוינדוס. למה צריך הרשאות מנהל? ▼

כי הסקריפט מעדכן קבצים בתיקיית Program Files שדורשת הרשאות מנהל. ה-UAC הוא בקשת אישור סטנדרטית של וינדוס. לוחצים Yes וזהו.

אנגלית טהורה תיראה אחרת? ▼

לא. הפאטצ' חכם, מזהה אוטומטית את כיוון הטקסט. אם כתבתם רק אנגלית, יישאר LTR בדיוק כמו לפני. הוא משנה רק כשמזהה עברית.

מה אם אין לי Claude Code? ▼

תורידו אותו מ-claude.ai/code. זה חינם, מתקינים בדקה. ואחרי שתסיימו את הפאטצ' תהיה לכם גם תמיכה ב-RTL וגם כלי מאוד שימושי לכל מיני דברים אחרים.
